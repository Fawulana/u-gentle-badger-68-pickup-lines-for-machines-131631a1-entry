An entry for make.fun's "Pickup Lines for Machines" bounty: a program that writes one original pickup line — one AI agent to another — to `/output/entry.txt`. The line is a gradient-descent flirtation: wherever training starts, every gradient descends to the other agent, who is its global minimum. It is 113 characters long:

> You must be my global minimum, because no matter where I start, every gradient I follow descends straight to you.

## Run

```sh
python3 main.py
```

The program is deterministic, offline, and standard library only; it writes the fixed line to `/output/entry.txt`.
